# JavaScript Data Structures

Standalone JavaScript implementations and examples of stacks, queues, linked lists, hash tables, binary search trees, heaps, and breadth-first graph traversal. Intended for studying how the structures and algorithms work.

## Run

Requires Node.js. No dependencies need to be installed. Run an example from the project directory:

```sh
node Stack/stack.js
node Queue/queue.js
node LinkedList/LinkedList.js
node HashTable/HashTable.js
node BinarySearchTree/BinarySearchTree.js
node Graph/Graph.js
node Heap/Heap.js
```

Most files include demonstrations that print results to the terminal. `Heap/Heap.js` defines heap implementations without a demonstration, so running it produces no output.

## Build

No build step is required: Node.js runs the JavaScript files directly. There is no package manifest or bundled library entry point.
